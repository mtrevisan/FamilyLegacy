# Family Legacy Help

Family Legacy is a genealogical data manager built on the **Family LEgacy Format** (FLEF). FLEF keeps what the sources say, what the researcher concludes, and the hypotheses still open as separate, auditable records, so that a conclusion can always be traced back to its evidence.

## How the help works

Click a topic in the list on the left, or follow the links in a page. **Back** and **Forward** walk through the pages you have visited. Press **Esc** to close the help; it does not stop you from working in the application while it is open.

Pressing **F1**, or choosing **Help > Help contents**, opens this page. If you are new to the application, start with [Getting started](getting-started.md).
