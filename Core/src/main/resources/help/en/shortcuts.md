# Keyboard shortcuts

The same list, always up to date, is in **Help > Keyboard Shortcuts...**.

## File

| Shortcut | Command |
|---|---|
| `Ctrl+N` | New file |
| `Ctrl+O` | Open file |
| `Ctrl+Shift+S` | Save as |
| `Ctrl+Q` | Exit |

## Edit

| Shortcut | Command |
|---|---|
| `Ctrl+Z` | Undo |
| `Ctrl+Y` or `Ctrl+Shift+Z` | Redo |

## Individual and group

These commands are in the **Individual** and **Group** menus (and in the **Place** menu for a place): the Edit menu has only Undo, Redo and Recent Changes.

| Shortcut | Command |
|---|---|
| `F2` | Edit the selected individual or group |
| `Ctrl+X` | Relocate the selected individual or group |
| `Del` | Delete the selected individual, group or place |

## View

| Shortcut | Command |
|---|---|
| `Ctrl+1` | Biological Tree |
| `Ctrl+2` | Sugiyama Graph |
| `Ctrl+3` | Ego Network |
| `Ctrl+4` | Chronomap |
| `Ctrl+L` | Tree: toggle the layout (vertical or horizontal) |
| `Ctrl+T` | Tree: show or hide the lifespans strip (in the ego network: the events bar) |
| `Ctrl+K` | Tree and graph: kinship between the root and a second person |
| `Ctrl+P` | Tree and graph: pedigree-collapse report |
| `F11` | Full screen |

## Navigate

| Shortcut | Command |
|---|---|
| `Ctrl+Left` | Back |
| `Ctrl+Right` | Forward |
| `Ctrl+J` | Jump to individual (or group) |
| `Ctrl+F` | Find record |
| `Ctrl+D` | Bookmark current view |
| Arrow keys | Move the selection to the nearest box in that direction (when the focus is not in a text field) |
| `Enter` | Make the selected box the new root |

In the Chronomap the **Left** and **Right** keys move the timeline by a month, and with `Shift` by a year.

## Tools and help

| Shortcut | Command |
|---|---|
| `Ctrl+Shift+A` | Research Assistant |
| `F1` | Help contents |
| `Esc` | Close the dialog that has the focus |
| `Ctrl+Z`, `Ctrl+Y` | In a dialog: undo and redo the last edit of the field |

On macOS, `Ctrl` is replaced by `Cmd` where the system convention says so.
