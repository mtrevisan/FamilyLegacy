## Parte 1 — Restart obbligatorio

### 1.1 `ApplicationRestarter.java`

```java
package io.github.mtrevisan.familylegacy.v2.ui.preferences;

import javax.swing.JOptionPane;
import javax.swing.SwingUtilities;
import java.awt.Window;
import java.io.IOException;
import java.nio.file.Path;
import java.util.ArrayList;
import java.util.List;
import java.util.Optional;


/**
 * Restarts the running application by spawning a new JVM with the same
 * command line and terminating the current process.
 *
 * <p>The new process is started with {@code inheritIO()} so its stdout,
 * stderr and stdin are connected to the same console as the current one.
 * A short pause lets the new process attach to the console before the
 * current JVM exits, which avoids the console window flashing closed on
 * Windows.</p>
 *
 * <p>If the restart cannot be performed — for example, when the JVM was
 * launched with a wrapper that does not report a command line, or when the
 * process spawn fails — the user is told to restart manually. In every case
 * the caller can count on {@link #restart(Window, String)} returning
 * before the JVM exits.</p>
 */
public final class ApplicationRestarter{

	/** Delay before {@code System.exit}, in milliseconds. */
	private static final int EXIT_DELAY_MS = 300;

	/** Prefix of the property that records the launcher command. */
	public static final String PROP_LAUNCH_COMMAND = "app.launch.command";


	private ApplicationRestarter(){}


	/* ======================================================================
	 *                          Public API
	 * ====================================================================== */

	/**
	 * Notifies the user that a restart is required, then restarts the
	 * application. The dialog is modal and blocking: the method does not
	 * return until the user has acknowledged it.
	 *
	 * @param owner  the window that owns the dialog; may be {@code null}
	 * @param reason a short sentence explaining why the restart is needed
	 */
	public static void restart(final Window owner, final String reason){
		JOptionPane.showMessageDialog(owner,
			reason + "\n\nThe application will restart now.",
			"Restart required",
			JOptionPane.INFORMATION_MESSAGE);

		if(!tryRestart())
			JOptionPane.showMessageDialog(owner,
				"Could not restart automatically.\n"
					+ "Please close and reopen the application.",
				"Restart failed",
				JOptionPane.WARNING_MESSAGE);
	}


	/* ======================================================================
	 *                          Internals
	 * ====================================================================== */

	private static boolean tryRestart(){
		final List<String> command = resolveLaunchCommand();
		if(command.isEmpty())
			return false;

		try{
			final ProcessBuilder pb = new ProcessBuilder(command)
				.inheritIO();
			pb.start();

			// Give the new process a moment to attach to the console
			// before we exit, so the console window does not flash.
			try{
				Thread.sleep(EXIT_DELAY_MS);
			}
			catch(final InterruptedException ignored){
				Thread.currentThread().interrupt();
			}
			System.exit(0);
			return true;
		}
		catch(final IOException ignored){
			return false;
		}
	}


	/**
	 * Reconstructs the command line used to launch the current JVM.
	 *
	 * <p>Two sources are consulted, in order:</p>
	 * <ol>
	 *   <li>the {@link #PROP_LAUNCH_COMMAND} system property, if the
	 *       application was launched through a wrapper that set it;</li>
	 *   <li>{@link ProcessHandle.Info#commandLine()} of the current
	 *       process, which returns the exact command line as the OS sees
	 *       it. This works on Linux, macOS and Windows on JDK 9+.</li>
	 * </ol>
	 *
	 * @return the command as a list of tokens, or an empty list when the
	 *         command line cannot be determined
	 */
	private static List<String> resolveLaunchCommand(){
		final String property = System.getProperty(PROP_LAUNCH_COMMAND);
		if(property != null && !property.isBlank())
			return tokenize(property);

		final Optional<String> commandLine = ProcessHandle.current()
			.info()
			.commandLine();
		if(commandLine.isPresent() && !commandLine.get().isBlank())
			return tokenize(commandLine.get());

		return List.of();
	}


	/**
	 * Splits a command line into tokens, honoring double quotes. This is a
	 * minimal parser good enough for the command lines generated by
	 * standard JVM launchers; it does not handle escaped quotes inside
	 * quoted segments, which do not appear in practice on any of the
	 * supported platforms.
	 */
	private static List<String> tokenize(final String commandLine){
		final List<String> out = new ArrayList<>();
		final StringBuilder buf = new StringBuilder();
		boolean inQuote = false;

		for(int i = 0; i < commandLine.length(); i ++){
			final char c = commandLine.charAt(i);
			if(c == '"'){
				inQuote = !inQuote;
			}
			else if(c == ' ' && !inQuote){
				if(buf.length() > 0){
					out.add(buf.toString());
					buf.setLength(0);
				}
			}
			else{
				buf.append(c);
			}
		}
		if(buf.length() > 0)
			out.add(buf.toString());

		return out;
	}

}
```

### 1.2 `AppearanceMenu` — semplificato

Rimuovi il metodo `onLanguageSelected` precedente e usa il restart obbligatorio:

```java
private static void onLanguageSelected(final Window owner, final Locale locale){
	final Locale current = AppearanceManager.savedLocale();
	if(sameLanguage(locale, current))
		return;

	// Persist first, so the new process picks it up on startup.
	AppearanceManager.applyLanguage(locale);

	// The locale change only takes full effect after restarting, because
	// some labels are baked into components at construction time.
	ApplicationRestarter.restart(owner,
		"The interface language has been changed to "
			+ locale.getDisplayLanguage(locale) + ".");
}
```

`AppearanceManager.applyLanguage` resta semplice: aggiorna `Locale.setDefault`, persiste, e basta. Non serve più refreshare l'albero dei componenti, perché stiamo per uscire:

```java
public static void applyLanguage(final Locale locale){
	Locale.setDefault(locale);
	AppPreferences.getInstance().setLanguageTag(locale.toLanguageTag());
}
```

`languageChangeRequiresRestart()` può essere rimossa: il restart è sempre imposto.

## Parte 2 — Framework di internazionalizzazione

### 2.1 Architettura

Ogni stringa visibile all'utente vive in un bundle. Il codice non contiene mai testo letterale.

```
src/main/resources/
  i18n/
    ui/
      messages.properties       <- fallback (inglese)
      messages_it.properties
      messages_de.properties
      ...
    report/
      report_messages.properties
      report_messages_it.properties
      ...
```

**Due bundle separati**: uno per la UI, uno per i report. Sono audience diverse — il report può essere in italiano anche se la UI è in inglese. Tenerli separati evita che un cambio di traduzione del report tocchi la UI.

### 2.2 `I18n.java` — helper unico per la UI

```java
package io.github.mtrevisan.familylegacy.v2.ui.i18n;

import com.ibm.icu.text.MessageFormat;

import java.io.IOException;
import java.io.InputStream;
import java.io.InputStreamReader;
import java.io.Reader;
import java.nio.charset.StandardCharsets;
import java.text.Normalizer;
import java.util.Locale;
import java.util.MissingResourceException;
import java.util.PropertyResourceBundle;
import java.util.ResourceBundle;


/**
 * Central accessor for the UI's localized strings.
 *
 * <p>Translations live in {@code i18n/ui/messages.properties} and its
 * locale-specific siblings (e.g. {@code messages_it.properties}). The
 * loader reads them as UTF-8, so any script can be stored literally
 * without {@code \\uXXXX} escapes.</p>
 *
 * <p>Plural- and gender-sensitive messages use ICU4J
 * {@link MessageFormat}, so languages with more than two plural forms
 * (Slavic, Arabic) and languages with grammatical gender (French, Russian)
 * are handled correctly. A message that does not depend on the count
 * should use {@link #t(String)}; one that does should use
 * {@link #plural(String, int, Object...)}.</p>
 *
 * <p><b>Runtime changes are not supported.</b> The bundle is loaded once
 * at class initialization with the default locale captured at that
 * moment. Changing the locale at runtime requires restarting the JVM,
 * which is exactly what the application does when the user picks a new
 * language.</p>
 */
public final class I18n{

	private static final String BUNDLE_BASE = "i18n.ui.messages";

	/** The bundle, resolved once against the current default locale. */
	private static final ResourceBundle BUNDLE =
		ResourceBundle.getBundle(BUNDLE_BASE, Locale.getDefault(), new Utf8Control());


	private I18n(){}


	/* ======================================================================
	 *                          Simple lookups
	 * ====================================================================== */

	/** Returns the localized string for {@code key}. Throws when the key is missing. */
	public static String t(final String key){
		return BUNDLE.getString(key);
	}

	/** Returns the localized string for {@code key}, or {@code fallback} when missing. */
	public static String t(final String key, final String fallback){
		try{
			return BUNDLE.getString(key);
		}
		catch(final MissingResourceException ignored){
			return fallback;
		}
	}

	/** Returns the localized string for {@code key} with {@link String#format} substitution. */
	public static String tf(final String key, final Object... args){
		return String.format(BUNDLE.getString(key), args);
	}


	/* ======================================================================
	 *                          ICU formatting
	 * ====================================================================== */

	/**
	 * Formats a plural-sensitive message using ICU4J. The pattern must use
	 * the CLDR plural syntax, e.g.
	 * {@code "{0,plural,one{# file}other{# files}}"}. The count is bound to
	 * argument {@code 0}; any additional arguments follow.
	 */
	public static String plural(final String key, final int count, final Object... extra){
		final String pattern = BUNDLE.getString(key);
		final Object[] args = new Object[extra.length + 1];
		args[0] = count;
		System.arraycopy(extra, 0, args, 1, extra.length);
		return new MessageFormat(pattern, Locale.getDefault()).format(args);
	}

	/** Same as {@link #plural(String, int, Object...)} but takes an explicit pattern. */
	public static String formatIcu(final String pattern, final Object... args){
		return new MessageFormat(pattern, Locale.getDefault()).format(args);
	}


	/* ======================================================================
	 *                          UTF-8 loader
	 * ====================================================================== */

	/**
	 * {@link ResourceBundle.Control} that loads {@code .properties} files
	 * as UTF-8 instead of ISO-8859-1. Needed because the standard loader
	 * mangles every non-ASCII character unless it is escaped as
	 * {@code \\uXXXX}.
	 */
	private static final class Utf8Control extends ResourceBundle.Control{

		@Override
		public ResourceBundle newBundle(final String baseName, final Locale locale,
				final String format, final ClassLoader loader, final boolean reload) throws IOException{
			if(!"java.properties".equals(format))
				return super.newBundle(baseName, locale, format, loader, reload);

			final String bundleName = toBundleName(baseName, locale);
			final String resourceName = toResourceName(bundleName, "properties");
			try(InputStream is = loader.getResourceAsStream(resourceName)){
				if(is == null)
					return null;
				try(Reader reader = new InputStreamReader(is, StandardCharsets.UTF_8)){
					return new PropertyResourceBundle(reader);
				}
			}
		}
	}

}
```

### 2.3 Convenzione dei nomi delle chiavi

Struttura gerarchica, prefisso per area:

```
menu.file.new              = New
menu.file.open             = Open…
menu.file.recent           = Open Recent
menu.file.recent.empty     = (no recent files)
menu.edit.undo             = Undo
menu.edit.redo             = Redo
menu.view.projection.tree  = Ancestor Tree
menu.view.fullscreen       = Full Screen
menu.individual.primary.add = Add Individual…
dialog.about.title         = About Family Legacy
dialog.about.message       = ...
button.ok                  = OK
button.cancel              = Cancel
button.yes                 = Yes
button.no                  = No
label.name                 = Name
label.sex                  = Sex
label.date                 = Date
error.file.not_found       = File not found: %s
error.file.save_failed     = Could not save the file: %s
```

**Regola**: la chiave descrive **dove** appare la stringa, non cosa dice. `menu.file.new`, non `new_file_menu_item`. Così se il testo cambia ("New" → "Create New"), la chiave resta valida.

**Un'eccezione**: i termini di dominio (nomi di record, tipi di evento) possono usare la loro chiave semantica: `event.birth`, `event.marriage`, `relationship.biological_child`.

### 2.4 Migrazione delle stringhe esistenti

Il codice attuale ha centinaia di stringhe come `new JMenuItem("New File")`, `new JButton("Save")`, `setTitle("About Family Legacy")`, ecc. La migrazione va fatta a strati.

**Passo 1** — inventaria tutte le stringhe visibili. Cerca in tutti i file `.java`:

```bash
grep -rn 'new JMenuItem\|new JButton\|new JLabel\|new JCheckBox\|new JRadioButton\|setTitle\|showMessageDialog\|showConfirmDialog' \
	src/main/java/ | grep '"'
```

Risultato: una lista di file + stringhe, che diventerà la lista di chiavi.

**Passo 2** — estrai a mano, partendo dalla `ApplicationMenuBar`. È il punto più visibile e il più citato dalla documentazione.

Prima:
```java
final JMenuItem newFile = new JMenuItem("New File", KeyEvent.VK_N);
```

Dopo:
```java
final JMenuItem newFile = new JMenuItem(I18n.t("menu.file.new"), KeyEvent.VK_N);
```

**Passo 3** — dialoghi e pannelli. `ReportDialog`, `IndividualRecordDialog`, `GroupRecordDialog`, ecc.

**Passo 4** — messaggi di errore. Sono i più facili da dimenticare; usa il pattern:

```java
JOptionPane.showMessageDialog(frame,
	I18n.tf("error.file.save_failed", path),
	I18n.t("dialog.error.title"),
	JOptionPane.ERROR_MESSAGE);
```

### 2.5 Plurale, genere, formato numerico

**Plurale** (inglese + slavo + arabo):

```properties
# messages.properties
dialog.delete_files.message={0,plural,one{Delete # file?}other{Delete # files?}}

# messages_it.properties
dialog.delete_files.message={0,plural,one{Eliminare # file?}other{Eliminare # file?}}

# messages_ru.properties
dialog.delete_files.message={0,plural,one{Удалить # файл?}few{Удалить # файла?}many{Удалить # файлов?}other{Удалить # файла?}}
```

Chiamata: `I18n.plural("dialog.delete_files.message", n)`.

**Genere** (utile in francese, tedesco, russo):

```properties
# messages_fr.properties
user.welcome={0,choice,0#Bienvenue|1#Bienvenu|2#Bienvenue}
```

Ma ICU choice è più verboso. Per il genere è spesso meglio usare pattern separati e lasciare al codice la scelta:

```properties
user.welcome.male=Bienvenu, %s
user.welcome.female=Bienvenue, %s
```

**Date e numeri**: usa `DateFormat.getDateInstance(SHORT)` e `NumberFormat.getInstance()`, che leggono automaticamente da `Locale.getDefault()`.

### 2.6 Cosa NON tradurre

- Identificatori del protocollo FLEF (`birth`, `marriage`, `biological_child`): sono valori di dati, non etichette.
- Nomi propri (`Family Legacy`).
- Nomi di file e cartelle.
- URL.
- Chiavi delle properties.

### 2.7 Aggiornamento al cambio lingua

Con il restart forzato, `I18n.BUNDLE` è caricato una sola volta con `Locale.getDefault()`. Non c'è bisogno di invalidare la cache, di rileggere il file, di aggiornare l'albero dei componenti. Il nuovo processo parte con la nuova lingua.

Questo elimina il 90% della complessità di i18n nelle applicazioni Swing, che è esattamente il motivo per cui il restart forzato è preferibile in questo caso.

| Cosa | Dove |
|---|---|
| Restart JVM dal processo corrente | `ApplicationRestarter` |
| Persistenza di lingua e font | `AppPreferences` |
| Applicazione lingua/font all'avvio | `AppearanceManager.applySaved()` |
| Menu di scelta lingua/font | `AppearanceMenu` |
| Restart obbligatorio al cambio lingua | `AppearanceMenu.onLanguageSelected` |
